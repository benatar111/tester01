# ⚖️ The Argument Settler

Two AI personas debate any topic you throw at them while a chaotic judge scores each round and declares a winner.

**Meet the debaters:**

- 🔥 **Blaze McHotTake** — Aggressive, dramatic, makes up statistics, drops mics
- 🧐 **Dr. Penelope Pontific VIII** — Pretentious, cites fake philosophers, adjusts monocle aggressively

**The judge:** The Honorable Judge Judy 2.0, who scores on categories like "Sheer Audacity" and "Unearned Confidence"

## Usage

```bash
# Interactive mode — pick a topic
node index.js

# Debate a specific topic
node index.js "is a hot dog a sandwich"

# Random spicy topic
node index.js --random
```

## How it works

1. You give a topic
2. Each debater gets assigned an opposing position
3. 3 rounds of arguments, each scored by the judge
4. Closing statements and a final verdict

Nobody learns anything. Everyone has a great time.
